# Speak

**AIの言葉に、声を。**

音声生成AIを使って、AIの言葉を読み上げるMCPツールです。文章の自動分割やユーザー辞書で、読み上げを好みに合わせられます。

AppDock 0.259.0以降。設定の「Speak」でMCP公開をONにすると、`appdock_speech_speak`を1つ公開する。初期状態はOFF。本体の「MCPツール」と同じ公開設定を編集する。

「設定」タブにはMCP公開・前後の文章・自動分割・再生開始・辞書変換、「ユーザー辞書」タブには単語の編集、「配布辞書」タブには取り込んだ辞書の管理を置く。各タブとJSONに切り替えてもSpeakの情報パネルを表示する。JSONタブは通常設定だけを扱い、辞書本文は含まない。

「辞書変換」の「英字の大文字・小文字を区別しない」は初期ON。半角英字A–Z／a–zを同じ文字として照合し、`hello`の登録で`Hello`や`HELLO`も置換する。OFFでは登録した表記と同じ大小文字だけを置換する。CSVの表記と置換されない文章は変更せず、日本語・全半角などの一致規則も保持する。大小文字だけ異なる登録がある場合、ONではユーザー辞書、配布辞書の一覧順、同じCSV内の先頭の順で採用する。OFFではそれぞれの表記を別の登録として扱う。どちらでも英単語内の部分一致は行わず、`key`と`board`から`keyboard`を分解して置換しない。切り替えはプレビューとMCPの両方へ反映し、辞書の再読み込みや索引の再構築を必要としない。

Applet IDは`at365.speak`、MCPモジュールIDは`at365.speak.read-aloud`。

「設定」タブの「前後の文章」で、「前に付ける文章」「後に付ける文章」を指定できる。初期値はどちらも空欄。空欄・空白や改行だけの項目は追加しない。「前の文章の後に改行を入れる」「後の文章の前に改行を入れる」はそれぞれ初期ONで、ON側は改行1つ、OFF側は区切りや空白を追加せず本文と直接つなぐ。本文と非空の追加文章の表記・前後空白・内部改行は保持するため、OFFでも入力した改行は取り除かない。

「前後の文章を追加するタイミング」は次の2通りから選ぶ。プレビュー・MCP・試聴で同じ設定を使う。

| 選択 | 処理 |
| --- | --- |
| 分割前に追加する（初期） | 前文＋本文＋後文を結合し、全体を辞書変換してから自動分割する。前後文は全体に1回ずつ付く。 |
| 分割後に各部分へ追加する | 本文を辞書変換して自動分割し、分割した各部分すべてに辞書変換済みの前後文を付ける。追加後には再分割しない。 |

分割後では本文・前文・後文をそれぞれ一度だけ辞書変換し、変換済みの本文を再置換しない。前後文と本文の境界をまたぐ辞書照合は行わない。分割の目安文字数は本文に使い、前後文を含む各部分はその文字数を超える場合がある。自動分割がOFFなら本文を1部分として前後文を付ける。辞書変換がOFFでも前後文は追加する。空の本文を前後の文章だけで読み上げる機能ではなく、MCPの本文は引き続き必須とする。

入力は本文`text`、任意の接続ID`connectionId`、接続名`connectionName`、ニュアンス`instructions`。本体MCP入口は認証・公開状態・入力形式の確認と本文/通常設定の保持だけを行い、HTTP 200と`{accepted:true}`を返す。Appletへの配送、辞書の準備・変換、文章分割、音声接続の解決、読み上げキュー登録・生成・再生の結果は待たない。処理開始と応答送信の順序は固定しない。

受信した処理は元の設定を使って順番に準備する。接続IDを優先し、未指定の場合だけ設定順の名前完全一致を使う。名前の省略・一致なしは既定接続。不明IDでは別接続へ切り替えず、受付後の準備失敗として本体の共通エラー通知とログへ報告する。受信応答は読み上げキューへの登録や音声生成・再生の成功を意味しない。準備中に提供元Appletが停止した場合も、その失敗を報告する。すでに本体TTSへ登録された読み上げは従来どおり本体が継続する。

自動分割は初期ON、目安300文字。各部分の先頭から目安文字数の位置を基準に前後の分割候補を探し、最も近い位置の直後で区切る。文字の種類による優先順位や探索距離の制限は設けず、同じ距離なら手前を選ぶ。残りが目安以下ならそのまま最後の部分にする。候補がなければ文の途中で切らず、その後の全文を1部分にするため、目安を大きく超える場合もある。

| 自動分割の設定 | 初期値・動作 |
| --- | --- |
| 分割方式 | 「指定した文字で分割」と「文単位で分割」（初期）から選ぶ。どちらも目安文字数に最も近い候補を選ぶ。 |
| 分割に使う文字 | `.!?。！？．｡`。入力した文字それぞれの直後を候補にし、連続した区切り文字は末尾だけを候補にする。読点・リーダーは初期の対象に含めず、必要な場合だけ追加する。空欄も指定できる。 |
| 改行を分割候補にする | ON。CRLF・LF・CR・Unicodeの行/段落区切りを対象にする。 |
| スペースを分割候補にする | OFF。ONでは半角/全角などのスペースとタブを対象にする。英文の途中で音声生成が分かれると、抑揚やつながりが変わる場合がある。 |

指定文字方式では文字と改行・スペースを同じ優先度で扱い、区切り文字自体は前の部分に残す。`！？`・`...`などの連続する指定文字と、その後の閉じ括弧も前の部分へ含め、その末尾まで含めた文字数で距離を比較する。分割文字を空欄にして改行・スペースもOFFにすると全文が1部分になる。

文単位方式ではJavaScript標準の`Intl.Segmenter`で文の区切りを判定する。指定文字・改行・スペースの3項目は非表示になり、分割判定にも使用しない。値は保持され、指定文字方式へ戻せば再び利用できる。目安文字数は両方式で共通。文に付く空白・改行・閉じ括弧は標準の判定に従う。略語・引用・文中の記号などで期待と異なる判定になる場合はプレビューで確認する。

両方式とも絵文字・URL・小数・英単語・辞書の置換語の途中を避け、元の空白と改行を保ち、空白だけの部分を作らない。分割OFFでは全文を1部分として送る。プレビュー・MCP・試聴で同じ分割設定を使う。

再生開始は「最初の1個」「指定個数」「全部」「最初の生成後に指定秒数」のいずれか。初期は1個、個数の初期入力2、秒数0。秒数は小数も指定でき、全生成が早く終わっても省略しない。待機中も次の部分を順番に生成する。

辞書の置換は初期ON・空。一覧の追加・編集はダイアログのOKでユーザー辞書CSVへ保存する。ページ切り替えのない1つのテーブルで表示する。大きな一覧は画面付近の行だけを描く仮想スクロールと全件対象の検索を使い、件数の上限は設けない。「表示範囲」のSectionは置かない。置換元と置換先は空白だけにできず、CSV内に同じ置換元が複数ある場合は先に出てきたレコードを採用し、取り込みを続ける。一覧の追加・編集では置換元の重複を入力エラーにする。大文字小文字・全半角・前後の空白は保持する。最長一致で1回だけ置換し、置換結果を再置換しない。ASCII英数字だけの単語は英単語の一部と一致しない。日本語は文字列一致。

「ユーザー辞書」タブの隣の「取り込み」からUTF-8のCSVファイルを選ぶか貼り付け、プレビューしてユーザー辞書全体を置き換える。ヘッダーなしの2列「置換元,置換先」。BOM・CRLF/LF・引用符内のカンマ/改行を扱う。不正な入力や保存競合では元の辞書を保持する。隣の「書き出し」は保存中のユーザー辞書をCSVファイルへ出力する。

「配布辞書」はCSVファイルを指定してプレビュー後に取り込む。一覧から名前・有効状態・優先順を変えられる。同じ置換元はユーザー辞書を最優先し、配布辞書同士では有効な辞書の一覧の上を優先する。異なる長さの置換元は引き続き最長一致で処理する。元のファイルは変更せず、AppDock内へCSVをコピーする。取り込んだCSVは重複行も含め原文を保存し、プレビュー・件数表示・検索では重複を除いた採用語を使う。更新は行の「再インポート」で行い、辞書の順序と有効状態を保つ。削除は登録と保存コピーだけを対象とする。自動取得・元ファイルの監視・他形式の変換は行わない。

辞書は起動・取り込み・編集・有効状態や順序の変更・保存先の切り替えで読み込み、統合した検索索引をメモリへ保持する。読み上げるたびのファイル読み込みや索引構築は行わない。保存先のCSVを外部で変更した場合は「再読み込み」を押す。読み込みや保存に失敗した場合、同じ保存先の直前の正常な辞書を保持し、設定画面へ案内を表示する。

保存先は本体のデータフォルダー内の`storage/at365.speak/shared/files/`、PC専用では`storage/at365.speak/devices/<端末名>/files/`。ユーザー辞書は`user.csv`、取り込んだ配布辞書は`source-<ID>.csv`。`catalog.json`には辞書名・順序・有効状態・件数・保存ファイル名・変更検査用のハッシュを記録し、単語と読みはCSVだけに保存する。共有／PC専用はそれぞれ独立した辞書を持ち、切り替えでコピーしない。辞書ファイルは通常設定のリセットでは削除しない。

「設定」タブの隣の「文章プレビュー」は入力を保存せず、選んだタイミングで前後の文章を加えた最終的な読み上げ全文と各部分を表示する。入力欄には元の本文を保持するため、「更新する」で前後の文章を重複して追加しない。音声サーバーへの通信・生成・再生は行わない。

同じ場所の「試聴」は文章と音声接続を選び、「試聴する」で実際に生成・再生する。Speakの現在の前後の文章・改行・辞書変換・自動分割・再生開始設定を使い、声や話し方は選んだ音声接続の設定に従う。「既定の接続」も選べる。試聴によって本体の既定接続やSpeakの設定・辞書を変更せず、入力した文章と接続の選択も設定には保存しない。受付後もダイアログに入力を残すので、そのまま試し直せる。接続がない場合は「音声生成AI」での登録を案内する。MCP公開がOFFでも利用でき、ダイアログを閉じても受付済みの読み上げは継続する。

受付済みの読み上げは公開OFFやApplet停止後も本体が継続する。認証撤回・明示停止・本体終了では取り消す。本体の通常通知や試聴へ、このAppletの辞書・分割を自動適用しない。

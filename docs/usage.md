# Speak

**AIの言葉に、声を。**

音声生成AIを使って、AIの言葉を読み上げるMCPツールです。文章の自動分割やユーザー辞書で、読み上げを好みに合わせられます。

AppDock 0.249.0以降。設定の「Speak」でMCP公開をONにすると、`appdock_speech_speak`を1つ公開する。初期状態はOFF。本体の「MCPツール」と同じ公開設定を編集する。

「設定」タブにはMCP公開・自動分割・再生開始・辞書のON/OFF、「ユーザー辞書」タブには単語の編集、「配布辞書」タブには取り込んだ辞書の管理を置く。各タブとJSONに切り替えてもSpeakの情報パネルを表示する。JSONタブは通常設定だけを扱い、辞書本文は含まない。

Applet IDは`at365.speak`、MCPモジュールIDは`at365.speak.read-aloud`。

入力は本文`text`、任意の接続ID`connectionId`、接続名`connectionName`、ニュアンス`instructions`。接続IDを優先し、未指定の場合だけ設定順の名前完全一致を使う。名前の省略・一致なしは既定接続。不明IDでは別接続へ切り替えない。本体が受け付けると`{accepted:true}`を返す。

自動分割は初期ON、目安300文字。段落・文末・読点・空白を使い、絵文字・英単語・置換語の途中を避ける。目安を超える場合もある。分割OFFでは全文を1部分として送る。

再生開始は「最初の1個」「指定個数」「全部」「最初の生成後に指定秒数」のいずれか。初期は1個、個数の初期入力2、秒数0。秒数は小数も指定でき、全生成が早く終わっても省略しない。待機中も次の部分を順番に生成する。

辞書の置換は初期ON・空。一覧の追加・編集はダイアログのOKでユーザー辞書CSVへ保存する。単語は1ページ100件で表示し、件数の上限は設けない。置換元と置換先は空白だけにできず、CSV内に同じ置換元が複数ある場合は先に出てきたレコードを採用し、取り込みを続ける。一覧の追加・編集では置換元の重複を入力エラーにする。大文字小文字・全半角・前後の空白は保持する。最長一致で1回だけ置換し、置換結果を再置換しない。ASCII英数字だけの単語は英単語の一部と一致しない。日本語は文字列一致。

「ユーザー辞書」タブの隣の「取り込み」からUTF-8のCSVファイルを選ぶか貼り付け、プレビューしてユーザー辞書全体を置き換える。ヘッダーなしの2列「置換元,置換先」。BOM・CRLF/LF・引用符内のカンマ/改行を扱う。不正な入力や保存競合では元の辞書を保持する。隣の「書き出し」は保存中のユーザー辞書をCSVファイルへ出力する。

「配布辞書」はCSVファイルを指定してプレビュー後に取り込む。一覧から名前・有効状態・優先順を変えられる。同じ置換元はユーザー辞書を最優先し、配布辞書同士では有効な辞書の一覧の上を優先する。異なる長さの置換元は引き続き最長一致で処理する。元のファイルは変更せず、AppDock内へCSVをコピーする。取り込んだCSVは重複行も含め原文を保存し、プレビュー・件数表示・検索では重複を除いた採用語を使う。更新は行の「再インポート」で行い、辞書の順序と有効状態を保つ。削除は登録と保存コピーだけを対象とする。自動取得・元ファイルの監視・他形式の変換は行わない。

辞書は起動・取り込み・編集・有効状態や順序の変更・保存先の切り替えで読み込み、統合した検索索引をメモリへ保持する。読み上げるたびのファイル読み込みや索引構築は行わない。保存先のCSVを外部で変更した場合は「再読み込み」を押す。読み込みや保存に失敗した場合、同じ保存先の直前の正常な辞書を保持し、設定画面へ案内を表示する。

保存先は本体のデータフォルダー内の`storage/at365.speak/shared/files/`、PC専用では`storage/at365.speak/devices/<端末名>/files/`。ユーザー辞書は`user.csv`、取り込んだ配布辞書は`source-<ID>.csv`。`catalog.json`には辞書名・順序・有効状態・件数・保存ファイル名・変更検査用のハッシュを記録し、単語と読みはCSVだけに保存する。共有／PC専用はそれぞれ独立した辞書を持ち、切り替えでコピーしない。辞書ファイルは通常設定のリセットでは削除しない。

「設定」タブの隣の「文章プレビュー」は入力を保存せず、置換後の本文と分割結果だけを表示する。音声サーバーへの通信・生成・再生は行わない。

受付済みの読み上げは公開OFFやApplet停止後も本体が継続する。認証撤回・明示停止・本体終了では取り消す。本体の通常通知や試聴へ、このAppletの辞書・分割を自動適用しない。

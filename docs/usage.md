# Speak

**AIの言葉に、声を。**

音声生成AIを使って、AIの言葉を読み上げるMCPツールです。文章の自動分割や個人辞書で、読み上げを好みに合わせられます。

AppDock 0.246.0以降。設定の「Speak」でMCP公開をONにすると、`appdock_speech_speak`を1つ公開する。初期状態はOFF。本体の「MCPツール」と同じ公開設定を編集する。

Applet IDは`at365.speak`、MCPモジュールIDは`at365.speak.read-aloud`。旧`at365.speech`版とは別のAppletとして扱い、保存済み設定・公開ON/OFFは引き継がない。旧版から切り替える場合は、同名MCPツールの二重提供を避けるため旧版をアンインストールしてから導入する。設定の移行・旧IDの別名は用意しない。

入力は本文`text`、任意の接続ID`connectionId`、接続名`connectionName`、ニュアンス`instructions`。接続IDを優先し、未指定の場合だけ設定順の名前完全一致を使う。名前の省略・一致なしは既定接続。不明IDでは別接続へ切り替えない。本体が受け付けると`{accepted:true}`を返す。

自動分割は初期ON、目安300文字。段落・文末・読点・空白を使い、絵文字・英単語・置換語の途中を避ける。目安を超える場合もある。分割OFFでは全文を1部分として送る。

再生開始は「最初の1個」「指定個数」「全部」「最初の生成後に指定秒数」のいずれか。初期は1個、個数の初期入力2、秒数0。秒数は小数も指定でき、全生成が早く終わっても省略しない。待機中も次の部分を順番に生成する。

個人辞書は初期ON・空。一覧の追加・編集はダイアログのOKで保存する。置換元と置換先は空白だけにできず、置換元の重複は禁止。大文字小文字・全半角・前後の空白は保持する。最長一致で1回だけ置換し、置換結果を再置換しない。ASCII英数字だけの単語は英単語の一部と一致しない。日本語は文字列一致。

補助操作からUTF-8の個人CSVを選ぶか貼り付け、プレビューして辞書全体を置き換える。ヘッダーなしの2列「置換元,置換先」。BOM・CRLF/LF・引用符内のカンマ/改行を扱う。不正な入力や保存競合では元の辞書を保持する。書き出しは同じ辞書をCSVファイルへ保存する。配布辞書の取り込みは含まない。

文章プレビューは入力を保存せず、置換後の本文と分割結果だけを表示する。音声サーバーへの通信・生成・再生は行わない。

受付済みの読み上げは公開OFFやApplet停止後も本体が継続する。認証撤回・明示停止・本体終了では取り消す。本体の通常通知や試聴へ、このAppletの辞書・分割を自動適用しない。
